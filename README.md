## Project Overview

This project presents an interactive Power BI dashboard analyzing the Top 10 Popular Bikes in India.  
It provides comparative insights on price, engine capacity, mileage, braking system, fuel tank capacity, and top speed.

The objective is to transform raw bike specification data into a structured, visually compelling business intelligence report.

---

## Business Objective

- Compare top bike models in the Indian market
- Analyze price vs performance
- Identify feature-based differentiation
- Support data-driven purchase decision analysis

---

## Dashboard Features

- Model selection filter
- Performance comparison metrics
- Price analysis
- Engine capacity insights
- Mileage range visualization
- Fuel tank capacity comparison
- Brake type and top speed analysis

---

## Tech Stack

- Power BI – Dashboard design & visualization
- Excel / CSV – Data source
- Data Modeling – Relationships & KPI creation
- DAX – Calculated measures

---

## Key Insights

- Higher engine capacity correlates with increased price.
- Touring and classic models dominate premium pricing segments.
- Fuel efficiency varies significantly across sports vs commuter models.
- Dual Disc ABS is common among high-performance bikes.
